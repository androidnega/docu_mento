cPanel Git: "fatal: a branch named 'main' already exists" — FIX (no SSH)
================================================================================

CAUSE
  cPanel (or your "Deploy" script) runs:  git checkout -b main
  That FAILS if branch "main" already exists. Use checkout (no -b) + pull.

WHAT TO DO IN cPanel (Git Version Control → Manage your repo)
  1) Open the repository → find "Deployment" / "Pull or deploy" /
     "Additional deploy commands" (wording varies by host).

  2) REMOVE any line containing:
       checkout -b main
       git branch main

  3) If you must paste commands, use ONLY this block (runs from repo root):

--------------------------------------------------------------------------------
git fetch origin
git checkout main
git pull origin main
--------------------------------------------------------------------------------

  4) If your host only has a "Pull" / "Update from remote" button and NO
     custom script: use that button only — leave extra deploy commands EMPTY.

IF YOU LATER GET SHELL OR SUPPORT CAN RUN A SCRIPT
  From the site’s repository root:
    bash scripts/cpanel-git-safe-pull.sh

That script checks whether "main" exists locally before using -b.
